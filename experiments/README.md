# Experiments Directory

This directory is reserved for empirical studies, heuristic benchmarking, metaheuristic parameter tuning, and comparative computational experiments.

## Experiment Categories:
1. **Convergence Studies**: Tracking iteration vs objective value for Genetic Algorithms, Simulated Annealing, and PSO.
2. **Computational Complexity**: Runtime scaling with respect to department count ($N \in \{6, 12, 20, 30, 50\}$).
3. **Multi-Objective Trade-offs**: Hypervolume and spread of Pareto frontiers balancing Material Handling Cost vs. Closeness Satisfaction.
4. **Layout Fingerprinting**: Sensitivity of algorithm performance to facility aspect ratios and flow density.
