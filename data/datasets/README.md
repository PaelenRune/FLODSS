# Benchmark Datasets Directory

This directory stores standard Operations Research and Facility Layout Optimization benchmark datasets for research and comparative validation.

## Standard Literature Benchmarks (To be curated in upcoming phases):
- **Armour & Buffa (1963)**: 20-department manufacturing plant case.
- **Nugent et al. (1968)**: Quadratic Assignment Problem (QAP) instances (sizes 12, 15, 20, 30).
- **Bazaraa (1975)**: Unequal area facility layout problem benchmark.
- **Welgama & Gibson (1995)**: 8-department continuous layout instances.
- **van Camp, Carter & Vannelli (1991)**: Layout benchmarks with complex aspect ratios.

## Schema Standard:
All problem datasets in this system adhere to the `FacilityLayoutProblem` Pydantic model format (see `data/examples/sample_plant.json`).
